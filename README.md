# Асинхронный Hacker News crawler

Учебный асинхронный краулер для `news.ycombinator.com`. Через заданный интервал
он читает главную страницу Hacker News, сохраняет метаданные top stories и
параллельно загружает страницу новости и ссылки из её обсуждения.

## Возможности

- периодический запуск без наложения циклов друг на друга;
- ограничение числа одновременных HTTP-запросов;
- таймауты, обработка сетевых ошибок и ограничение размера ответа;
- дедупликация ссылок внутри новости и между запусками;
- атомарная запись файлов, чтобы не оставлять повреждённые результаты;
- однократный режим, удобный для cron и проверки;
- unit- и интеграционный тесты без обращения в интернет.

## Установка

Требуется Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
```

## Запуск

Один цикл, первые 10 новостей:

```bash
hn-crawler --once --limit 10 --output data
```

Постоянная работа каждые 60 секунд:

```bash
hn-crawler --interval 60 --limit 30 --concurrency 10 --output data
```

То же без установленного console script:

```bash
python -m crawler.cli --once --limit 10
```

Остановка постоянного режима — `Ctrl+C`. Полный список параметров:

```bash
hn-crawler --help
```

## Результаты

В каталоге `data/stories/<id>.json` хранится карточка новости со списком URL.
Содержимое ссылок записывается в `data/pages/<sha256>.bin`, а рядом находится
JSON с исходным URL и Content-Type. Уже сохранённые URL повторно не скачиваются.

## Структура

```text
src/crawler/
├── cli.py       # CLI и запуск event loop
├── crawler.py   # асинхронная оркестрация и HTTP
├── models.py    # модель новости
├── parser.py    # разбор HTML
└── storage.py   # файловое хранилище
```

Краулер предназначен для учебного использования. Выбирайте разумный интервал
и не создавайте лишнюю нагрузку на Hacker News и сайты по внешним ссылкам.
